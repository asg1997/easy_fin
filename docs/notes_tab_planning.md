# Вкладка «Заметки» (TODO + заметки)

## Цель

Добавить в боковую навигационную панель новую вкладку **«Заметки»** с двумя разделами:

1. **TODO** — локальные задачи (синхронизация с GitHub **не нужна**).
2. **Заметки** — короткие текстовые записи (синхронизация с GitHub **обязательна**).

Оба раздела поддерживают создание, редактирование и удаление. Удаление — **жёсткое** (строка стирается из хранилища, без флага «удалён»).

---

## Принятые решения

| Вопрос | Решение |
|--------|---------|
| Где в UI | Новая вкладка в `MainNavPage` рядом с «Отчеты» / «Документы» / «Настройки» |
| Внутренняя структура вкладки | Два пункта (сегменты / подвкладки): **TODO** и **Заметки** |
| Хранение TODO | `SharedPreferences` (JSON), **не** в SQLite |
| Синхронизация TODO | Нет — как шаблоны отчётов |
| Хранение заметок | Таблица Drift в `easy_fin.sqlite` |
| Синхронизация заметок | Да — автоматически через существующий GitHub sync файла БД |
| Удаление TODO / заметок | Hard delete (`DELETE` / удаление из JSON), без soft-delete |
| Лимит длины текста заметки | Нет |
| Разделение между заметками | Визуальное (отступ / разделитель / карточка-блок), без иерархии и папок |
| Soft-delete / архив | Не делаем |

### Почему TODO не в SQLite

GitHub sync в Easy Fin работает на уровне **всего файла** `easy_fin.sqlite`. Если положить TODO в ту же БД, задачи уедут на другое устройство вместе с остальными данными.

Чтобы TODO остались только локальными **без** отдельной синхронизации таблиц, их храним в `SharedPreferences` — тот же подход, что у шаблонов отчётов (`report_templates_storage`).

Заметки живут в SQLite → после «Синхронизировать» попадают на GitHub вместе с финансовой базой.

> Если позже понадобится sync TODO — перенести в SQLite тривиально. Отдельный per-table sync не планируем.

## Реализация (отклонения от черновика)

- В таблице Drift колонка содержимого называется `content` (не `text`): имя `text` конфликтует с методом Drift `Table.text()`.
- В domain-модели поле по-прежнему `Note.text`.
